Sin conectar

Si quiere que la oficina y los celulares de los encargados vean los mismos pagos, conecte una base de datos gratuita de Google (Firebase). El plan gratuito alcanza para miles de pagos al mes. Si no la conecta, todo funciona igual, pero cada equipo guarda sus propios datos.

Pasos para crear la base de datos gratuita (unos 15 minutos, una sola vez)
  1. Entre a console.firebase.google.com con una cuenta de Gmail de la empresa y toque Crear un proyecto. Nómbrelo, por ejemplo, hc-pagos. Puede desactivar Google Analytics. El plan que queda es Spark (gratis): no pide tarjeta.
  2. En el menú, entre a Compilación → Authentication → Comenzar. Active Correo electrónico/contraseña.
  3. En la pestaña Usuarios, toque Agregar usuario y cree un correo y contraseña para cada persona que va a registrar pagos.
  4. Entre a Compilación → Firestore Database → Crear base de datos. Elija una ubicación (por ejemplo us-central1) y modo de producción.
  5. En Firestore, pestaña Reglas, borre lo que hay, pegue estas reglas cambiando los correos por los que creó en el paso 3, y toque Publicar: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email in [
          'oficina@gmail.com',
          'encargado@gmail.com'
        ];
    }
  }
}
  6. Vaya a Configuración del proyecto (ícono de engranaje) → Tus apps → ícono </> (Web). Póngale un nombre y toque Registrar app. Copie el bloque const firebaseConfig = { … } y péguelo abajo.

Para los demás equipos: descargue el programa ya conectado y ábralo en cada computadora o celular, o súbalo a GitHub Pages para usarlo con un enlace. Solo tendrán que iniciar sesión con su correo.

Tipo de cambio

Se usa solo para convertir totales en los reportes. Los recibos muestran la moneda original.

Instalar en celular o computadora

  1. Android (Chrome): abra la página, toque ⋮ → Agregar a pantalla principal.
  2. iPhone (Safari): toque Compartir → Agregar a inicio.
  3. Computadora: guarde este archivo en el escritorio y ábralo con doble clic, o en Chrome o Edge use el ícono de instalar de la barra de direcciones si la página está publicada en internet.
